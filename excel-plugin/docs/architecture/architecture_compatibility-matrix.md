# Office.js Compatibility Matrix

Generated by `src/utils/officeSpike.ts::runCompatibilitySpike()`.
Pre-populated from Office.js requirement set documentation.
Live results to be confirmed via Diagnostics > "Run Spike" in Excel.

This matrix covers only the Excel Office.js surface. Looker Studio and Looker
Data Studio direct bypasses the add-in and XMLA flow: it uses the standard
gateway JDBC path without LookML. An optional customer-supplied Looker
instance can consume a generated LookML adapter. Their contract is defined in
`looker-and-looker-cloud-core-client-specs.md`.

## Known Limitations

- Office.js cannot programmatically create external OLAP PivotTables (`PivotTables.add()` only supports local worksheet ranges)
- `Workbook.connections.add()` availability varies by requirement set — falls back to manual instructions
- Local PivotTable creation via Office.js requires ExcelApi 1.9+ (gated in code)
- Context menu support requires Office 2016+ with VersionOverridesV1_1
- Some operations may require user interaction or native Excel UI
