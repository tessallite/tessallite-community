# Excel Plugin Documentation

Single-tree documentation root for the Tessallite Excel plugin subproject. Start here, pick a domain, then read that domain's `_INDEX.md`.

**Domains**

- **architecture/** — Specs, frontend design, compatibility matrix, UX review. Stable reference.

- **execution/** — Active plans, remaining work, deferred item tracking. Update as work progresses.

- **reviews/** — Code review findings and fix reports from each implementation phase. Historical record.

- **archive/** — Superseded backend-change specs and duplicate documents. Cold storage.

**Carve-outs (not part of this tree)**

- `README.md` at the plugin root.
- `src/` source code.
- Build/config files (`package.json`, `tsconfig.json`, `vite.config.ts`, `vitest.config.ts`, `manifest.xml`).
