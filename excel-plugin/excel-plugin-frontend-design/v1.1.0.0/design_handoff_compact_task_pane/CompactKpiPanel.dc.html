What changed
  1. Same compact shell as Analyse: 36px header, 32px tabs, 22px footer.
  2. Three header rows → two. Search + Certified checkbox + Refresh + Scorecard in one 34px row (All/Certified chips become the checkbox). Count and status totals in a 26px strip; clicking a status dot filters the list.
  3. KPI cards (~80px) → 30px rows. Status dot · name · value / target · trend arrow · Table and Chart icon buttons with tooltips. Target moves inline after the value.
  4. Folder groups collapse — click the header.
  5. One scrollbar for the whole tab — thin, light grey, auto-hides; header, tabs and footer stay fixed.
  6. Chips match Report Builder — same 14px Certified pill on certified rows, same pill style for the status counts.
  7. Ungrouped KPIs list after the last folder with no header; deprecated KPIs are struck through with an orange Deprecated pill (as in Report Builder).
  8. Loading, load-error, empty and no-match states kept — toggle below the pane. A selected status filter fills the pill with an × to clear.
  9. Unevaluated KPIs show a grey dot and "not evaluated"; the chart icon is disabled with an explanatory tooltip.
  10. Evaluation-error banner kept as a state (toggle below the pane).

Result: 4 KPIs visible → all 13 visible without scrolling.
