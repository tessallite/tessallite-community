What changed
  1. Header 48→36px. Tessallite mark stays; clicking it shows name and version. Project / Model shown as a dropdown title; one popover holds Project, Model and Persona selects. Profile moves under the gear.
  2. Project bar and Model select removed (−88px) — both live in the title popover.
  3. Tabs 44→32px. "Ask Tessallite" → "Ask".
  4. "Build report" title removed. Zones are self-explanatory.
  5. Zones → 26px single rows. Captions become tooltips on the label; selected fields are inline chips. Filter chips are dashed green and click to edit (operator + values dialog); a Clear-layout icon sits at the right of Values when anything is staged.
  6. One 30px toolbar replaces 2 button rows + insert-mode row + helper text: Table / Chart / Pivot / Templates | CUBE / Connect / Refresh, all icon-only with tooltips; Live checkbox at the right.
  7. All five field sections (Measures, KPIs, Named lists, Dimensions, Hierarchies) collapse — click the header. Hierarchies expand to levels, each addable to Rows. KPI rows get an Insert-options menu (row / value / goal / status / card / formula). Click the project title or the gear to see their popovers.
  8. Extra states (offline banner, incompatible-fields warning, refresh details, measure details, dimension member preview, KPI insert-options menu, sort popover) — toggle via the "Show states" strip or click the relevant control.
  9. Field rows keep every control as 22px icon buttons with tooltips — measures: insert as function, CUBE formula, add to Filters, add to Values (green); dimensions: details, preview, Filters, Columns, Rows (green).
  10. Fields header → search bar only, with a Certified checkbox and a sort icon inline.
  11. Footer 28→22px, status only.
  12. One scrollbar for the whole tab (zones, toolbar, search and fields scroll together) — thin, light grey, auto-hides; header, tabs and footer stay fixed.

Result: chrome shrinks from ~640px to ~260px. Field list gets ~435px instead of ~50px — roughly 8× more.
