Looker Cloud Core - Not Required

Looker Cloud Core is not required for Tessallite's Looker Studio/Data Studio direct integration and is not an active delivery or validation target.

Use Looker Studio Direct Connection for the PostgreSQL connector path. If a customer later supplies a compatible Looker instance, generated LookML can be evaluated through the optional Looker-hosted workflow.

Looker Studio -> PostgreSQL connector -> Tessallite Gateway :5433
  -> Tessallite query router -> source warehouse

This direct path does not consume or execute LookML.
