# Tessallite Third-Party Notices

Last updated: 2026-06-23

Tessallite includes third-party open-source and commercial dependencies. Each
third-party component remains subject to its own license terms.

This file is a release placeholder for the root notice file. Before any public
Community or Enterprise release, replace this placeholder with a generated,
version-specific notice file covering:

- Python package dependencies for every service;
- npm package dependencies for the frontend, shared UI, Excel plugin, website,
  and tools that ship;
- base container images;
- bundled system packages;
- embedded parsers, drivers, fonts, and runtime assets;
- any commercial or non-open-source components included in a release artifact.

The release process must fail if generated notices still contain unfinished
placeholder wording.

Current known notice source to replace:

- `tessallite/THIRD_PARTY_NOTICES`

That file is incomplete and must not be shipped as the final notice document.
