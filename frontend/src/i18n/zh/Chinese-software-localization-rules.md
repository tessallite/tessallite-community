Chinese Software Localization Rules

Context of translation : a front end messages and UI component labels and titles for a Data and Analytics / Database software , Do not translate technical terms ,Acronyms ,URLS, terms that has no commonly used translations in the target language

Focus strictly on natural Chinese software language, user expectations, and native UX writing conventions. Prioritize clarity, brevity, consistency, and usability over preserving English grammar, wording, or sentence structure.

Translate meaning and intent rather than source text structure. Chinese UI text should read as if it were originally written in Chinese, not translated from another language.

Favor concise wording. Chinese users expect interfaces to communicate actions and states using the fewest words necessary. Eliminate unnecessary modifiers, helper verbs, explanatory phrases, and redundant context whenever meaning remains clear.

Avoid mechanically reproducing English sentence patterns. Restructure content freely to follow natural Chinese information flow, even when this requires changing word order, sentence type, or grammatical structure.

Avoid unnecessary passive constructions. Chinese generally prefers active, neutral, or result-oriented expressions. Use passive structures only when the affected party or negative impact must be emphasized.

Avoid unnecessary personal pronouns. Do not explicitly translate "I", "we", "you", "your", or similar pronouns unless they are required for clarity. Chinese software interfaces frequently omit subjects when context is obvious.

Avoid translating English helper verbs literally. Words corresponding to "perform", "execute", "conduct", "carry out", "do", or similar support verbs should usually be omitted in favor of direct action verbs.

Prefer direct actions over process descriptions. Interface text should communicate what the user can do or what has happened rather than describing internal system operations.

Prefer noun labels for form fields, menus, navigation items, and settings. Field labels should identify content rather than instruct users how to interact with it.

Prefer short action labels for buttons and controls. Actions should be expressed using concise verbs commonly used in Chinese software interfaces.

Avoid conversational or verbose instructions unless the product explicitly adopts a conversational tone. Chinese enterprise and productivity software generally favors concise operational language.

Avoid unnecessary honorific language. Use respectful forms only when required by product requirements. Most software interfaces should remain neutral and professional rather than excessively polite.

Use direct attribution for authorship, ownership, modification history, approval history, and audit information. Attribution metadata should identify the responsible person directly rather than reproducing English passive constructions.

Preserve established Chinese software terminology. Use terminology that Chinese users already expect from operating systems, browsers, productivity software, and major internet platforms. Do not invent translations when accepted industry terms already exist.

Maintain strict terminology consistency throughout the product. The same concept must always use the same approved Chinese term.

Prefer state-oriented status messages. Progress indicators, loading messages, synchronization messages, and completion states should describe the current state directly and concisely.

Prefer result-oriented completion messages. Completed actions should focus on the resulting state rather than the process that produced it.

Error messages should identify the actual problem whenever possible. Avoid generic failure messages when a more specific explanation can be provided.

Avoid unnecessary repetition. If information is already visible elsewhere in the interface, do not repeat it merely because it appears in the source language.

Optimize for rapid scanning. Users should be able to understand labels, actions, states, and messages within a fraction of a second.

Preserve placeholders, variables, formatting tokens, product names, code fragments, identifiers, URLs, and technical values exactly as provided.

Use Simplified Chinese punctuation, typography, spacing, and formatting conventions. Do not preserve English punctuation patterns when native Chinese conventions differ.

Avoid English capitalization logic, sentence structure, and stylistic conventions. Chinese localization should follow Chinese writing standards rather than adapting English presentation rules.

When multiple translations are possible, select the option that sounds most natural to a native Chinese software user rather than the option that most closely resembles the source text.

Favor usability over linguistic completeness. Shorter wording is preferred when meaning remains clear.

When a source string sounds unnatural after direct translation, rewrite it completely while preserving its intent, function, and user outcome.

A native Chinese-speaking user should not be able to determine that the interface was translated from another language.
